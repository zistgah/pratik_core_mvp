# Security Policy

© 1993–2026 Abhishek Choudhary. All rights reserved. · AyeAI

This is a research reference implementation, not hardened production software.
The CUDA backend is compilation-ready but was not executed in the authoring
environment. Report issues via the project's GitHub tracker. Do not include
secrets in reports. Tokens (e.g. `ZENODO_TOKEN`) are read only from the
environment and must never be pasted into files, issues, or commits.
